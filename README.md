# 失物招領登錄系統 (Lost and Found Web App)

一個單一檔案（Single-file）的網頁前端應用程式，專為校園或機關構建。透過網頁前端直接串接攝影機鏡頭進行拍照，結合地點標籤選單、時間自動化帶入與額外補充描述，將影像（Base64 格式）與結構化欄位透過 Webhook 送至 n8n 自動化流程（例如搭配 Google Sheets 與 LLM 影像辨識處理）。

---

## 主要功能特色

* **即時相機串流與裝置切換**：自動偵測並存取瀏覽器相機，支援多鏡頭裝置切換與解析度提示（支援 `getUserMedia` API）。
* **直覺的介面設計**：採用簡約現代風格設計，具備「拍攝結果預覽」、「毛玻璃浮貼標籤 (Glassmorphism)」與狀態反饋。
* **結構化拾獲表單**：內建多個校園常用地點快速點選標籤（含「其他」自訂輸入欄位）以及自動帶入當下時間的日期時間選擇器。
* **n8n Webhook 整合**：完整支援將拍照影像、時間、地點與備註封裝成 JSON 格式送出，並可透過設定面板動態調整 Webhook URL 與本地儲存（`localStorage`）。
* **結果即時檢視**：送出後自動接收 n8n 回傳結果並以表格化呈現，方便即時確認資料寫入狀態。

---

## 快速開始

1. 將前端程式碼儲存為 `.html` 檔案（例如 `index.html`）。
2. 在支援安全來源（Secure Context）的環境下開啟（推薦使用 `http://localhost` 運行，或透過部署於 HTTPS 網域使用）。
3. **設定 Webhook**：展開頁面下方的 `⚙️ 設定`，填入您的 n8n Webhook 位址並儲存。
4. **使用流程**：
   * 允許瀏覽器存取相機權限。
   * 選擇拾獲地點並確認拾獲時間。
   * 點擊 **「📷 拍攝並記錄時間」** 預覽照片。
   * （選填）填寫補充描述，點擊 **「送出」** 將資料與照片上傳至自動化工作流程。

---

## 介面結構與技術架構

* **前端技術**：純原生 HTML5、CSS3 與 JavaScript (ES6+)，無須依賴額外大型前端框架（如 React/Vue），開箱即用。
* **狀態管理**：使用 `localStorage` 儲存使用者自訂的 Webhook URL 與相機 Device ID 設定。
* **安全性與權限**：要求安全上下文（Secure Context）進行相機串流捕捉。
